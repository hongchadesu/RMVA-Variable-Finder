# VF · 变量查找器 (Variable Finder)

面向 **RPG Maker VX Ace / RGSS3** 的运行时调试脚本：在游戏测试运行中扫描整个工程，查出**某个变量究竟在哪些地方被使用**。

**版本 2.10**

## 用途

- 排查变量冲突
- 找出空闲（未被使用）的变量
- 确认变量当前值
- 定位使用该变量的具体位置（地图事件 / 公共事件 / 敌群）

## 安装

1. 在 RPG Maker VX Ace 中按 `F11` 打开脚本编辑器
2. 在 **`Main` 的上方**新建一个脚本页（必须放在 `Main` 上方）
3. 用记事本打开下表中的 `.rb` 文件，`Ctrl+A` 全选、`Ctrl+C` 复制
4. 回到脚本编辑器，点进该脚本页，`Ctrl+A` 全选、`Ctrl+V` 覆盖粘贴

> **粘贴自检**：脚本文件第 1 行必须是 `=begin`，说明段结束处是单独一行的 `=end`。
> 如果脚本页第 1 行不是 `=begin`，说明复制时漏了开头，请重新全选复制。
>
> 放在默认脚本上方也可以 —— 本脚本会等默认脚本加载完毕再开始工作。

## 打开方式

测试运行时按 `F6`；也可以在事件的「脚本」指令里写：

```ruby
VF.open
```

## 按键

| 按键 | 作用 |
| --- | --- |
| `↑` `↓`（`←` `→`） | 选择 / 移动（选字检索时用方向键在字表里移动） |
| 数字键 `0-9` | 直接跳到指定变量编号 |
| `Enter` / `Z` / `空格` | 查看使用位置；选字检索时 = 选中该字 |
| `Q` / `W` | 翻页 |
| `F5` | 重新扫描整个工程 |
| `F6` | 开关本查找器 |
| `F7` | 切换显示范围（只看用过的 / 已命名 + 用过的） |
| `F8` | 跳页：输入页码直接跳过去 |
| `F9` | 打字检索：键盘输入关键词实时过滤（英文、数字） |
| `F10` 或 键盘 `A` / `S` 键 | 选字检索：挑字组成关键词实时过滤（**支持中文**） |
| `Esc` / `X` | 返回上一层 / 清除检索 / 关闭 |

> `F10` 在部分 RGSS 版本中不存在，此时使用键盘 `A` 键。提示行会始终显示当前**真正生效**的按键。
>
> 选字检索的字表会列出变量名里出现过的全部文字（中英文都有），按出现次数排序；一页放不下就用 `F8` 跳页或 `Q` `W` 翻页。

## 检索规则

`F9` 与 `F10` 共用同一套规则：关键词与「变量编号（四位补零）」和「变量名」做**不区分大小写**的包含匹配，命中结果直接显示在变量列表里；数字跳编号、`F8` 跳页在结果中同样可用。

## 扫描范围

- 地图事件全部页面（含事件出现条件里用到的变量）
- 公共事件
- 敌群（战斗事件）
- 变量操作 `122`、条件分支 `111`
- 文本里的 `\V[n]`
- 脚本指令里的 `$game_variables[n]`

## 用户设置

在脚本的 `module VF` 开头（`#== 用户设置 ==` 区块）可调整：

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `ENABLE_HOTKEY` | `true` | 是否允许用快捷键 `F6` 打开 |
| `ENABLE_IN_RELEASE` | `false` | 正式版（非测试运行）是否也允许打开 |
| `SCAN_MAPS` | `true` | 扫描地图事件 |
| `SCAN_COMMON` | `true` | 扫描公共事件 |
| `SCAN_TROOPS` | `true` | 扫描敌群战斗事件 |
| `MAX_PER_VAR` | `200` | 每个变量最多记录多少条使用位置 |
| `CHAR_LIST_MAX` | `0` | 选字检索里最多列出多少个字；`0` = 不限制（全部列出） |

## 注意

- 默认**只在测试运行（`$TEST`）下可以打开**，正式版按 `F6` 无效。需要在正式版也能用，就把 `ENABLE_IN_RELEASE` 改成 `true`。
- 本脚本**只读取工程数据，不会修改任何东西**。
- `F9` 打字检索需要 `Win32API` 读取键盘；如果当前 RGSS 不支持，该功能会自动停用并给出提示，其它功能（含选字检索）不受影响。
